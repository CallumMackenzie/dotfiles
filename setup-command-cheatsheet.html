Oil file manager

-Open the current file's parent directory
EnterOpen selected file or directory
Ctrl+pPreview selected file
Ctrl+sOpen in a vertical split
Ctrl+hOpen in a horizontal split
g?Show all Oil shortcuts

Oil is editable: rename or delete lines, then use :w to apply file operations.

Jupyter notebooks

SpacejrRun current cell
SpacejnRun current cell and advance
SpacejaRun all cells
]j / [jNext / previous cell
SpacejlRun current line
Visual + SpacejvRun selected code
SpacejoOpen or enter the current cell's output
SpacejhHide cell output
SpacejxInterrupt execution
SpacejRRestart kernel
SpacejiManually initialize the Neovim kernel
SpacejeSave notebook, embed outputs, and export rendered HTML

.ipynb files auto-start the kernel. Cells are separated with # %%.

Terminal, tmux & Neovim essentials

Ctrl+b, then sOpen tmux's session chooser
Ctrl+b, then NJump to the next pane with an unread Pi notification
piLaunch Pi; completion notifications return to this tmux pane
:wSave
:q / :wqQuit / save and quit
:e pathOpen a file
:bdClose current buffer
:vsplit pathOpen a vertical split
:split pathOpen a horizontal split
Ctrl+w, then h/j/k/lMove between splits
Ctrl+wcClose current split
Ctrl+w=Equalize split sizes
:tabe pathOpen file in a new tab
gt / gTNext / previous tab

LaTeX · VimTeX

SpacellStart or stop continuous compilation
SpacelvOpen the current PDF in macOS Preview
SpacelVPreview the first PDF page inside Neovim
j / kNext / previous page in the terminal PDF preview
SpacelpPreview the equation under the cursor with Nabla
Tab / Shift+TabMove through LaTeX snippet fields
Shift+Cmd+clickJump from a location in Skim back to its source

Press q to close the terminal preview. Tectonic builds PDFs; TexLab supplies completion and diagnostics.
